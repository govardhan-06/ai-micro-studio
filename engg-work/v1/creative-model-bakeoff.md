# Creative model bake-off

This is the T4 scoring sheet. `prompts/creative-bakeoff.json` is the single ten-prompt fixture; every candidate model receives the same prompts and settings. The runner labels outputs A/B/C so scoring can be performed blind before model names are revealed.

Score each response from 0 (poor) to 10 (excellent): hook, originality, narrative coherence, twist/payoff, emotional pull, visual potential, and amount of editing required. For editing need, 10 means little editing is required.
